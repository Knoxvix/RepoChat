# RepoChat

A private chat app. Your messages are locked on your own device before they are sent, so only you and the person you write to can read them.

## What you need
- A free GitHub account
- The link to this chat site
- The person who shared this site must add you to their repository first. Ask them to do it and accept the invitation GitHub emails you.

## Step 1. Make your access token (once)
The token is a long code that lets the app send your locked messages. You make it once and paste it in the first time you log in on a device.

1. Sign in to GitHub and open **Settings → Developer settings → Fine-grained tokens**.
2. Choose **Generate new token** and give it any name.
3. Under **Repository access**, choose **Only select repositories** and pick the repository of this chat.
4. Under **Permissions → Repository permissions**, set **Contents** to **Read and write**.
5. Choose **Generate token**, copy it and keep it somewhere private.

## Step 2. Sign up
1. Open the chat site.
2. Type a username and a password of 10 or more characters.
3. Paste your token and choose **Log in or sign up**.

Next time on the same device, you only need your username and password.

## Step 3. Start chatting
1. Choose **New chat** and type your friend's username. They must have signed up too.
2. Write a message and choose **Send**.

New messages appear in a few seconds.

## Check it's really them
Under the chat name you will see a **safety number**. Ask your friend to read theirs to you in person or on a call. If both numbers match, nobody is pretending to be them. If the number ever changes, check with your friend before you keep chatting.

## Install it like an app
- **Phone:** Open the site in your browser, open the browser menu and choose **Add to Home screen** or **Install app**.
- **Computer:** Look for the install icon in the address bar of Chrome or Edge.

## Please remember
- **Your password cannot be reset.** If you forget it, your keys are lost and you will need a new username.
- **A new device starts fresh.** You can log in with your username, password and token, but your old messages won't appear there.
- **Use one device at a time** for the same account.
- **Log out on shared computers** using the **Log out** button.
- Message text is private. If the chat repository is public, other people can still see who is talking to whom and when.
